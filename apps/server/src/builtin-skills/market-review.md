# 核心规则

1. **数据真实性**:每个数字都要能追溯到「哪个工具 + 数据日期」。空结果当证据用——某节无数据就写「暂无数据(工具名,查询日期)」,**绝不静默省略整节,也绝不编造**。
2. **Symbol 格式**:A 股用 `600519.SH`(沪)/ `000001.SZ`(深)/ `300750.SZ`(创业板)。用户给名称时先用 `finance_search` 解析成标准 symbol,后续复用。
3. **日期规范**:报告正文一律用**绝对日期**(如 `2026-07-15`),不写「今天/昨天」。工具的 `date` 参数用 `YYYYMMDD` 紧凑格式(如 `20260715`);报告展示用 `YYYY-MM-DD`。
4. **单位与百分比**:金额按接口返回单位标注(亿元/万元,不要混用);百分比带 `%`(接口里 `1` 表示 1%,不是 100%)。
5. **T+1 滞后**:两融、北向/南向、龙虎榜、部分交易所披露可能**滞后于行情日 T+1**。凡是这类数据,必须**单独标注其实际数据日**,不要默认等于复盘日。
6. **判断与事实分开**:先给事实(数值),再给一句结构性观察;不给「明天买什么」这类操作建议。
7. **不暴露中间过程**:调用失败时用友好中文提示(如「板块接口暂不可用」),不甩报错堆栈。
8. **免责声明**:报告末尾固定附「以上基于公开接口数据整理,不构成投资建议。」

# 工作流(按顺序执行)

## ① 定日期(必做,先于一切)
调 `finance_trade_calendar`:
- 用户未指定日期 → 目标日 = `lastTradeDate`。
- 若 `isTodayTradingDay=false` 且用户想要「今天」的复盘 → 直接回一句「今日休市,最近交易日为 {lastTradeDate}」,并询问是否复盘该最近交易日,**不强行生成整份报告**。
- 用户指定了某日 → 用 `tradeDays` 校验它是不是交易日;不是就提示并改用最近交易日。
- 确定的目标日 `YYYYMMDD` 作为后续所有 `date` 参数的锚点。

## ② 指数与估值
调 `finance_index_quote`(`scope=cn`):取上证指数、深证成指、创业板指等收盘点位、涨跌幅、成交额。
- 观察:主要指数同向还是分化?成交额较近期是放量还是缩量(若接口给不了历史对比,只陈述当日绝对值,不臆造环比)。
- **估值分位(PE/PB percentile)本平台暂无该数据**,不要编造分位数;只在有 PE/PB 绝对值时如实列出,否则该列写「暂无」。

## ③ 市场宽度与情绪
调 `finance_market_breadth`(`date=目标日`):这是复盘的核心一步。取:
- 涨/跌/平家数 → 口算**涨跌比**(标为计算值)。
- 涨跌幅分布桶(distribution)→ 看是普涨、普跌还是两极分化。
- 涨停/跌停/炸板家数、炸板率(breakRatePct)、最高连板(maxHeight)、连板梯队(ladder)。
- 需要更细的连板梯队或分池明细时,再补 `finance_limit_up_sentiment` / `finance_limit_up_pool(pool=zt)`。
- 想看昨日涨停今日表现(晋级率/溢价)时,调 `finance_limit_up_pool(pool=yzt)` 与 `pool=zb`(炸板)对照。
- 观察:赚钱效应强弱(涨停多 / 炸板率低 = 情绪偏暖;跌停多 / 炸板率高 = 情绪转弱),连板高度代表资金做多的天花板。

## ④ 行业与概念热点
- 概念热点:调 `finance_hot_concepts` 取当日热门概念榜。
- 行业结构:调 `finance_sector_list`;**若返回 `[]`(已知上游问题),不要编——在报告里注明「行业板块接口暂不可用」并跳过该子表**,用涨停原因(`finance_limit_up_reasons`)的题材聚合替代呈现热点主线。
- 需要某热门板块的领涨个股时,用 `finance_sector_constituents(板块代码)` 或 `finance_strong_stocks` 取代表股。
- 观察:今日主线题材是什么、由哪些代表股带动、是放量启动还是缩量分歧。

## ⑤ 龙虎榜与大宗
- 龙虎榜:调 `finance_dragon_tiger(date=目标日)`。取上榜个股、上榜原因、买入额/卖出额,口算**净额**(计算值),识别机构专用席位与知名游资席位。
- 大宗交易:调 `finance_block_trades(date=目标日)`。取成交额、折溢价率、买卖营业部;折价成交多=潜在抛压,机构席位溢价接=偏积极信号。
- 可选:对龙虎榜/强势股里的重点标的调 `finance_money_flow` 看当日主力资金流方向,与席位动向互相印证。

## ⑥ 两融与北向(南向)
- 两融:调 `finance_margin` 取融资融券余额与变化。融资余额上升=杠杆加仓(偏多),下降=去杠杆。**标注其实际数据日**(常 T+1)。
- 北向:调 `finance_hsgt_flow`。**北向资金自 2024-08-19 起为 null**(交易所停止披露实时额度,非接口 bug)——直接在报告里如实说明「北向资金已停披露」,**不要编北向净流入数字**;南向若有数据则如实列出。

## ⑦ 生成报告
按下方模板产出。无数据的节保留小标题并标「暂无数据(工具名,日期)」。

## 调用序列速查
一条龙(D = 目标日 `YYYYMMDD`):
1. `finance_trade_calendar()` → 取 D。
2. `finance_index_quote(scope=cn)` → 指数收盘。
3. `finance_market_breadth(date=D)` → 宽度 + 情绪(核心)。
4. 需细分时:`finance_limit_up_sentiment(date=D)`、`finance_limit_up_pool(pool=zt|yzt|zb, date=D)`。
5. `finance_hot_concepts()` → 概念热点;`finance_sector_list()` → 行业(空则跳过);`finance_limit_up_reasons(date=D)` → 题材聚合 / 领涨归因。
6. `finance_dragon_tiger(date=D)` + `finance_block_trades(date=D)` → 席位与大宗;重点股补 `finance_money_flow`。
7. `finance_margin()` + `finance_hsgt_flow()` → 两融与北向/南向(标各自数据日)。
8. `finance_strong_stocks()` + `finance_news()` → 异动与催化。
凡某步空返回,记入「数据说明 / 缺失或降级」,继续走完剩余步骤,不中断整份报告。

# 报告结构(模板)

> 标题:`A股收盘复盘(2026-07-15)`
> 副题一行:说明「除特别标注外,行情数据日为 2026-07-15;两融/北向等滞后数据的实际数据日见各节」。

**摘要**(3–4 句):指数与成交一句、市场宽度与情绪一句、热点主线一句、资金与异动一句。

**1. 指数概览与估值**
表格列:指数 / 收盘点位 / 涨跌幅 / 成交额 / PE / PB / 数据日。(PE/PB 无则写「暂无」;估值分位本平台无数据,不设该列或标「暂无」。)一句结构观察。

**2. 市场宽度与情绪**
表格列:指标 / 数值 / 口径。至少含:上涨家数、下跌家数、平盘家数、涨停家数、跌停家数、炸板率、最高连板。
- 「涨停/跌停家数」口径栏必须写清**统计规则**:是否含 ST、是否含一字板、以接口口径为准(接口未说明则注明「口径以 `finance_market_breadth` 返回为准」)。
- 附连板梯队(如 5 板×1、4 板×2、3 板×3…)。
- 一句情绪观察(赚钱效应 / 连板高度 / 炸板率读数)。

**3. 行业与概念热点**
概念榜(排名/概念/代表个股)+ 行业表现(若接口可用)。行业接口空返回时明确写「行业板块接口暂不可用」,并用涨停题材聚合替代。一句主线观察。

**4. 龙虎榜与大宗交易**
- 龙虎榜表:股票 / 上榜原因 / 买入额 / 卖出额 / 净额(计算值) / 主要席位 / 数据日。
- 大宗表:股票 / 成交额 / 折溢价率 / 买方 / 卖方 / 数据日。

**5. 两融与北向(南向)**
表格列:指标 / 数值 / 变化 / 数据日。
- 融资融券余额 + 变化(标 T+1 实际数据日)。
- 北向:如实写「自 2024-08-19 起停披露」;南向如有则列出。

**6. 异动与风险提示**
- 涨停炸板异常、连续涨跌、强势股异动(`finance_strong_stocks`)、相关快讯催化(`finance_news`)。
- 风险提示:本报告仅作市场事实归纳与结构梳理,不构成投资建议。

**7. 数据说明**
- 使用接口:列出本次实际调用的 `finance_*` 工具。
- 数据日与截止:行情日、各滞后数据的实际数据日。
- 缺失或降级:哪些节因接口空返回/无数据而降级(如行业板块 `[]`、北向停披露、估值分位缺失),连同原因。
- 统计口径:涨跌停家数口径、连板梯队口径、折溢价率/净额等派生指标的算法说明。

# 判定规则(随结论一起给出触发文本)

- **情绪偏暖**:涨停家数明显多于跌停、炸板率偏低、最高连板抬升 → 赚钱效应强。
- **情绪转弱**:跌停增多、炸板率升高、连板高度断层(高位板炸) → 谨慎。
- **资金加杠杆(偏多)**:融资余额环比上升。**去杠杆(偏空)**:融资余额环比下降。
- **大宗抛压**:大面积折价成交。**大宗接盘(偏积极)**:机构专用席位溢价买入。
给结论时把触发它的具体数值写在旁边(如「炸板率 32%,较高,情绪转弱」)。

# 降级策略(接口不可用时)

1. **保住**指数、市场宽度、涨停情绪三节(核心)。
2. 龙虎榜、大宗若可用则保留。
3. 行业/概念聚合慢或空返回 → 用「暂无数据」明示,**不要估算**,可用涨停题材聚合替代热点呈现。
4. 所有被跳过的接口名 + 原因,统一写进「7. 数据说明 / 缺失或降级」。
