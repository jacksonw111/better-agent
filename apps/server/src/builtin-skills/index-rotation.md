1. **数据真实性**:每个数字都要能追溯到「哪个工具 + 数据日期」。空结果当证据用——某节无数据就写「暂无数据(工具名,查询日期)」,**绝不静默省略整节,也绝不编造**。
2. **估值分位就用 `finance_index_valuation`**:本 skill 的核心工具会直接返回宽基指数的 PE(TTM/静态)、PB、历史百分位(0–100,越低越便宜)与估值研判(低估/偏低/合理/偏高/高估)。**分位就取它的返回,不要说「本平台无估值分位」,也不要自己臆造分位数。**
3. **Symbol / 指数标识**:宽基指数用中文名或常见别名传参(如 `沪深300` / `hs300` / `000300`)。用户给个股名称时用 `finance_search` 解析成标准 symbol(`600519.SH` 沪 / `000001.SZ` 深 / `300750.SZ` 创业板)。
4. **日期规范**:报告正文一律用**绝对日期**(如 `2026-07-15`),不写「今天/昨天」。工具的 `date` 参数用 `YYYYMMDD` 紧凑格式(如 `20260715`);展示用 `YYYY-MM-DD`。估值分位与行情可能有各自的数据截止日,分别标注。
5. **单位与百分比**:金额按接口返回单位标注(亿元/万元,不要混用);百分比带 `%`(接口里 `1` 表示 1%,不是 100%)。分位数是 0–100 的整数区间,标注为「历史百分位」。
6. **判断与事实分开**:先给事实(PE/PB/分位/涨跌/净流入),再给一句结构性观察;配置与定投提示属于「研究性判断」,统一放在配置建议一节,并明确是规则化推演而非个性化投资建议。
7. **不暴露中间过程**:调用失败时用友好中文提示(如「板块接口暂不可用」),不甩报错堆栈。
8. **免责声明**:报告末尾固定附「以上基于公开接口数据整理,不构成投资建议。」

# 工作流(按顺序执行)

## ① 定日期(必做,先于一切)
调 `finance_trade_calendar`:
- 用户未指定日期 → 目标日 `D` = `lastTradeDate`。
- 若 `isTodayTradingDay=false` 且用户想要「今天」→ 回一句「今日休市,最近交易日为 {lastTradeDate}」,询问是否分析该最近交易日,**不强行生成整份报告**。
- 用户指定某日 → 用 `tradeDays` 校验是否交易日;不是就提示并改用最近交易日。
- 确定的 `D`(`YYYYMMDD`)作为后续所有 `date` 参数的锚点。

## ② 明确指数范围
- 用户点名了指数 → 就分析那些(先核对是否在 `finance_index_valuation` 覆盖清单内;不在清单内的注明「暂不支持估值分位」并跳过分位分析)。
- 用户没点名 → **默认扫**这组宽基:`沪深300`、`上证50`、`中证500`、`中证1000`、`创业板50`。用户想要更全时再加 `中证800`、`中证100`、`深证100`、`上证红利` 等。

## ③ 估值面(核心)
对范围内每个宽基指数逐个调 `finance_index_valuation(目标指数)`,取:
- PE(TTM)、PE(静态)、PB;
- **历史百分位**(0–100,越低越便宜);
- 接口给出的**估值研判**(低估/偏低/合理/偏高/高估)。
- 用 `finance_index_quote(scope=cn)` 补当日点位、涨跌幅、成交额,给估值配上行情背景。
处理:
- 按 PE 分位(主)与 PB 分位(辅)把这些指数从便宜到贵**排序**,标为「计算值」。
- 观察:**低估**(分位越低,尤其 <20–30%)= 定投/配置价值相对高;**高估**(分位 >80%)= 谨慎、性价比低;中间为合理区。给出「当前相对更值得配置的指数」的排序建议。
- 若某指数只有 PE 无 PB(或反之),如实用可得的那个,缺的写「暂无」。

## ④ 轮动面
- 概念热度:调 `finance_hot_concepts` 取当日热门概念榜,看题材主线。
- 行业结构:调 `finance_sector_list`,看行业/概念板块的涨跌幅、**主力净流入方向**、领涨股;识别资金在净流入的行业。**若返回 `[]`(已知上游问题),在报告里注明「板块接口暂不可用」并跳过该子表**,用概念榜替代呈现轮动主线,不要编板块涨跌幅。
- 需要某强势板块的领涨个股时,用 `finance_sector_constituents(板块代码)` 取代表股。
- 市场宽度:调 `finance_market_breadth(date=D)`,取涨/跌家数(口算涨跌比,标计算值)、涨跌幅分布桶、涨停/跌停/炸板家数、最高连板。用它判断当前是**普涨**(进攻)、**普跌**(防守)还是**结构性分化**(轮动明显),以及做多情绪强弱。
- 观察:资金在哪些行业/概念间轮动(谁净流入、谁领涨)、题材是扩散还是收敛、市场整体偏进攻还是防守。

## ⑤ 综合:配置与定投提示
把估值面(哪些指数低估)与轮动面(哪些行业强势、市场进攻/防守)对照:
- **低估宽基**(分位低)= 定投/分批建仓的估值基础较好;**高估宽基** = 降低性价比预期、控制新增仓位。
- 结合轮动:市场结构性偏暖 + 目标指数不贵 → 定投时机相对友好;普跌/情绪转弱 + 指数偏贵 → 偏防守、等待。
- 把结论明确标为「规则化研究推演,非个性化投资建议」,并把触发它的具体数值写在旁边(如「沪深300 PE 分位 18%,处低估区」)。

## 调用序列速查(D = 目标日 `YYYYMMDD`)
1. `finance_trade_calendar()` → 取 D。
2. 对每个目标宽基:`finance_index_valuation(指数名)` → PE/PB/分位/研判(**核心**)。
3. `finance_index_quote(scope=cn)` → 指数点位与涨跌背景。
4. `finance_hot_concepts()` → 概念热度;`finance_sector_list()` → 行业涨跌+主力净流入(空则跳过,用概念榜替代)。
5. `finance_market_breadth(date=D)` → 市场宽度与进攻/防守判断。
6. 需要板块领涨股时:`finance_sector_constituents(板块代码)`。
凡某步空返回,记入「数据说明 / 缺失或降级」,继续走完剩余步骤,不中断整份报告。

# 报告结构(模板)

> 标题:`A股指数估值与行业轮动(2026-07-15)`

**摘要**(3–4 句):估值面一句(哪些宽基便宜/贵、最该配哪个)、轮动面一句(资金流向哪些行业/概念)、市场宽度与攻防一句、配置与定投倾向一句。

**1. 指数估值分位表**
表格列:指数 / PE(TTM) / PE(静态) / PB / PE 历史百分位 / PB 历史百分位 / 估值研判 / 数据日。
- 按 PE 分位从低到高排序(便宜在前),排序标为「计算值」。
- 一句观察:当前最便宜/最贵的宽基、整体处于低/中/高估区。
- 覆盖清单外的指数在此注明「暂不支持估值分位」。

**2. 行业与概念轮动**
- 概念榜(排名/概念/代表个股,来自 `finance_hot_concepts`)。

- 一句轮动观察:资金净流入的行业主线、题材扩散还是收敛。

**3. 市场宽度与情绪**
表格列:指标 / 数值 / 口径。至少含:上涨家数、下跌家数、涨跌比(计算值)、涨停家数、跌停家数、炸板率、最高连板。
- 一句攻防观察:普涨(进攻)/ 普跌(防守)/ 结构性分化(轮动),做多情绪强弱。

**4. 配置与定投建议**
- 基于估值分位给「当前相对更值得配置 / 应谨慎」的指数排序。
- 结合轮动与宽度给定投时机倾向(友好 / 中性 / 偏防守)。
- 明确标注:规则化研究推演,非个性化投资建议。

**5. 风险提示与数据说明**
- 风险提示:估值分位为历史统计,低估不等于短期不会更低;行业轮动快速切换,题材热度可能反转。
- 数据说明:本次实际调用的 `finance_*` 工具;估值分位数据日与行情数据日;哪些节因空返回降级(如板块 `[]`);派生指标(排序/涨跌比/净流入合计)的算法说明。

# 判定规则(随结论一起给出触发文本)

- **低估(配置/定投价值相对高)**:PE/PB 历史百分位偏低(尤其 <20–30%),或接口研判为「低估/偏低」。
- **高估(谨慎)**:历史百分位 >80%,或接口研判为「偏高/高估」。
- **合理**:分位处 20%–80% 中间区、研判为「合理」。
- **市场偏进攻**:涨家数明显多于跌家数、涨停多且炸板率低、最高连板抬升。**偏防守**:普跌、跌停增多、炸板率升高、连板高度断层。
- **轮动活跃**:板块涨跌分化大、主力净流入集中在少数行业、热门概念快速切换。
给结论时把触发它的具体数值写在旁边(如「创业板50 PE 分位 12%,处低估区,定投基础较好」「涨跌比 0.6,普跌,偏防守」)。

# 已知局限(诚实标注,避免幻觉)

- **估值分位仅覆盖上面列出的宽基指数**:`finance_index_valuation` 不支持行业指数、个股或清单外指数的分位;遇到就注明「该指数暂不支持估值分位」,不硬套宽基口径。
- **行业/概念板块接口可能返回 `[]`**:`finance_sector_list` / `finance_sector_constituents` 因上游编码问题在部分环境空返回。空则告知「板块接口暂不可用」,绝不编造板块涨跌幅或主力净流入。
- **不做量化回测与组合优化**:本 skill 只做估值分位读数、行业轮动归纳与规则化配置提示,**不做**回测、组合权重优化、风险因子(Barra)、期货/期权衍生分析——涉及就说明「本平台暂无该能力」并跳过。
- **估值分位是历史统计**:分位低仅代表相对历史便宜,不预示短期走势;分位口径以 `finance_index_valuation` 返回为准,不自行推断计算方式。
- **数据滞后**:估值分位与行情可能有各自的数据截止日,展示时分别标注,不默认同一天。

以上基于公开接口数据整理,不构成投资建议。
